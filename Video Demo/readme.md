# 🎥 BookStore - Project Demo

## 📖 About

This repository contains the demonstration video of the **BookStore** MERN Stack project.

The video shows the main features of the application, including authentication, book management, order processing, and role-based dashboards.

---

## 🎬 Demo Includes

* 🏠 Home Page
* 🔐 Login & Registration
* 👤 User Dashboard
* 🏪 Seller Dashboard
* 🛡️ Admin Dashboard
* 📚 Book Management
* 🛒 Cart & Checkout
* 📦 Order Management
* 📱 Responsive Design

---

## 🛠️ Technologies Used

* React.js
* Node.js
* Express.js
* MongoDB
* Bootstrap
* JWT Authentication

---

## 🎯 Purpose

This video demonstrates the working of the BookStore application and highlights the major functionalities developed using the MERN stack.
